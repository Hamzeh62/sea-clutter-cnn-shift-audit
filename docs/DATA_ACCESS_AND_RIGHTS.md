# Data access and redistribution

The underlying radar recordings are third-party IPIX CDF observations. They are **not included** here. The 887 MiB derived window cache is also omitted. The author's authorization to redistribute original or raw-data-equivalent derived recordings is not established; contact legitimate data custodians for acquisition terms.

This archive includes original research outputs (detector-score arrays, calibration summaries, checkpoint weights, generated tables and vector plots). Their redistribution is subject to author licensing and review for any original-data leakage.

To redo raw radar experiments, independently obtain IPIX recordings through an authorized source, reconstruct the window cache with the historical protocol (including documented limitations), and run the original scripts with the correct environment. No unverified download URL is supplied.
